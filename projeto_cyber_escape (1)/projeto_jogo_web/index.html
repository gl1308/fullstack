Sobre o jogo

Cyber Escape é um jogo de sobrevivência em que o jogador precisa desviar de inimigos e coletar energia para sobreviver o máximo possível.

O objetivo é conseguir a maior pontuação possível antes de perder toda a vida. Conforme o tempo passa, o jogo fica mais rápido e difícil.

Características

  • Jogo desenvolvido com HTML5 Canvas
  • Movimentação fluida
  • Sistema de pontuação
  • Aumento progressivo da dificuldade
  • Visual moderno
