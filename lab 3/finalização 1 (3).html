Introdução

C++ é uma linguagem de programação compilada multi-paradigma e de uso geral. Desde os anos 1990 é uma das linguagens comerciais mais populares.

Java é uma linguagem orientada a objetos desenvolvida na década de 90 por uma equipe liderada por James Gosling.

Java possui estrutura semelhante à linguagem C e compartilha várias características com C++.
